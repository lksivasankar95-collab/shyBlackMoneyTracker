# Expense Tracker - ShyBlack

Track Smarter. Save Better.

A premium, privacy-first personal finance management application built with React, Vite, Capacitor, and TailwindCSS. Features offline-first architecture, PIN/biometric security, multi-language support, and comprehensive financial tracking.

## Features

- 💰 Transaction tracking (income/expenses)
- 📊 Budget management
- 💳 Debt & EMI tracking
- 🎯 Savings goals
- 📈 Net worth tracking
- 💼 Wealth management
- 📄 Document vault
- 📑 Reports & exports (PDF, CSV, HTML)
- 🔐 PIN & biometric security
- 🌐 Multi-language (English, Hindi, Tamil, Telugu, Kannada)
- 📱 Android & PWA support
- 🔄 Backup & restore (encrypted)
- 📊 Financial health score
- 📅 Financial calendar & timeline
- 🏦 Account center

## Tech Stack

- **Frontend**: React 18
- **Build Tool**: Vite 4
- **Styling**: TailwindCSS 3
- **Mobile**: Capacitor 5 (Android)
- **Charts**: Recharts
- **PDF**: jsPDF + jspdf-autotable
- **i18n**: i18next + react-i18next
- **OCR**: Tesseract.js

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Run tests
npm test
```

## Android Build

```bash
npm run build
npx cap sync
npx cap open android
```
